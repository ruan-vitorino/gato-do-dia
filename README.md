🐱 Cat of the Day

A simple website that shows a random cat image using TheCatAPI.

🌍 Live: https://gato-do-dia.vercel.app

## Features

- Random cat generator  
- Breed filter  
- Download image  
- Copy image link  
- Save favorites (stored in your browser)  
- Personal counter (seen by you)  
- Global counter (seen by everyone)  

## About

This project is completely free and non-profit.  
It was created for learning and experimentation purposes.

There are no ads, no tracking beyond basic hosting analytics, and no commercial intent.
